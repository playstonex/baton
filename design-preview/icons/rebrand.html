Baton Rebrand · 名称 × 图标 概念集

参考同类 AI Agent 产品(Claude / Gemini / Cursor / Raycast)的图标语言:单一几何符号 + 渐变 + 暗底。 每个方案 = 新名称 + 匹配图标。选定后我会同步改名(app.json / iOS 显示名)并重打全平台图标。 单图预览:?t=1 … ?t=6

Swarm 蜂群

一群 agent 协同作战。六边形蜂巢 = 群体智能,中心发亮的格子是正在工作的那个。

Prism 棱镜

一句指令进入,拆解成多路 agent 并行。白光进,光谱出。

Relay 接力

任务在 agent 之间接力传递,永不停歇。双箭头 = 交接与推进。

Orbit 轨道

所有 agent 围绕同一个中枢运转。你在中心,它们各就其轨。

Flux 流

指令与结果双向流动,循环不休。两条轨道 = 输入与输出的永恒回路。

Spark 星火

一次点击,点燃整条 agent 流水线。主星 + 伴星,呼应多 agent 编排。
